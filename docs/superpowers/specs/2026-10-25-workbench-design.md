# 日常工作台

为一位使用者提供中文待办、笔记、常用链接，适应办公室电脑、家中电脑与手机。
采用一个联网服务与 SQLite 数据库；各设备登录同一服务读写同一数据。
选择依据是多设备使用需求；纯浏览器本地存储无法自动共享数据，暂不采用。
技术选择由实现者作出：Python 3.12+、Flask、Waitress、无前端构建依赖。

第一版支持分类、新建、编辑、删除、待办完成、搜索、JSON 导出与退出登录。
无多人协作、附件或离线编辑。每 30 秒获取更新，切回页面也刷新。
编辑和删除携带版本号；旧版本返回冲突提示，避免覆盖另一设备的数据。
单人密码登录、会话 cookie、同源请求保护、登录限速；用户内容以纯文本呈现。
初次运行生成本地随机密码文件，密码与数据库不进入 Git。

开发环境只监听回环地址。正式跨设备使用必须有 HTTPS 地址、持续在线的进程、
持久化数据目录与备份；本次不购买服务或声称已完成公开部署。
